# Arc-3-and-Arc-3-Modification-Comparison

implementation of Arc-3 and Arc-3 modified to solve Constraint Satisfaction Porblem of 9x9 sudoku problem in every stage of difficulty.

## Getting Started

1. Install prerequisites:
   - Python 3.10 or higher
   - Git
2. Clone this reposistory:

```sh
git clone https://github.com/hazueuenx/arc-3-and-ar-3-modification-comparison.git
cd arc-3-and-ar-3-modification-comparison
```

3. Setup virtual environment

```sh
pyhton -m venv .venv
source .venv/bin/activate # in powershell use .\.venv\Scripts\Activate.ps1
pip install requirements.txt
```

4. Run the program

```sh
python "Final Program.py"
```

5. Select the menu to run the algorithm.
